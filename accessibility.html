Erklärung zur Barrierefreiheit

Stand: 25. November 2026 · Bewertungsmethode: automatisierte Prüfung (IBM Equal Access Accessibility Checker, Policy WCAG 2.2) in der CI plus manuelle Tastatur- und Screenreader-Tests gemäß docs/accessibility-testing.md.

Geltungsbereich

Diese Erklärung gilt für die Web-Anwendung „Kompetenzbrille“ (Anzeige und Editor) unter schnaitter.github.io/Kompetenzbrille/.

Konformitätsstatus

Die Anwendung ist mit WCAG 2.2 Stufe AA weitgehend konform. Alle automatisierten Prüfläufe (Programm-, Framework- und Matrix-Sicht in Deutsch und Englisch, Hilfe- und Modul-Dialoge, Editor) melden keine Verstöße; Tastaturbedienung, Fokusführung, Kontraste, Sprachumschaltung und Statusmeldungen wurden manuell geprüft.

Bekannte Einschränkungen

  • Die eingebundenen Quellen-PDFs (Curricula und Framework-Dokument) sind nicht durchgängig barrierefrei aufbereitet; sie werden schrittweise ersetzt (siehe Issue #74 im Repository).
  • Die Matrix ist eine zweidimensionale Tabelle; auf sehr schmalen Bildschirmen wird horizontal gescrollt (nach WCAG 1.4.10 für 2D-Inhalte zulässig). Die sticky erste Spalte kann beim Scrollen Zellen überdecken; fokussierte Zellen werden automatisch in den sichtbaren Bereich geholt.

Feedback und Kontakt

Barrieren bitte als Issue im GitHub-Repository melden (gern mit Reproduktionsschritten und Angabe der assistiven Technologie). Wir bemühen uns um Antwort innerhalb von zwei Wochen.

Durchsetzungsverfahren

Bleibt eine Meldung ohne Reaktion, kann die für den Sitz der anbietenden Stelle zuständige Marktüberwachungsbehörde bzw. Schlichtungsstelle eingeschaltet werden.

Accessibility statement

Date: 25 November 2026 · Method: automated checks (IBM Equal Access Accessibility Checker, WCAG 2.2 policy) in CI plus manual keyboard and screen-reader tests per docs/accessibility-testing.md.

Scope

This statement covers the “Kompetenzbrille” web application (viewer and editor) at schnaitter.github.io/Kompetenzbrille/.

Conformance status

The application is largely conformant with WCAG 2.2 level AA. All automated scan states (program, framework and matrix views in German and English, help and module dialogs, editor) report zero violations; keyboard operation, focus management, contrast, language switching and status announcements were tested manually.

Known limitations

  • Embedded source PDFs (curricula and framework document) are not fully accessible yet and are being replaced step by step (repository issue #74).
  • The matrix is a two-dimensional table and scrolls horizontally on very narrow screens (permitted by WCAG 1.4.10 for 2D content). Focused cells are scrolled into view automatically so the sticky first column cannot obscure them.

Feedback

Please report barriers as issues in the GitHub repository, ideally with reproduction steps and your assistive technology. We aim to respond within two weeks.
